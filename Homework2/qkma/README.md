# Report
1. This dashboard is designed to explore book popularity through various features across different genres.
2. I manually classified the book genres into supergenres and applied this consistent categorization across all three visualizations to ensure data alignment.
3. The barchart serves as the data overview. When click one bar, the heatmap performs a drill-down to show the temporal details and trends of the specific subgenres.
4. Also apply the tooltips and highlighting, when hover over the bar, the dashboard displays precise data attributes and counts.
5. Use different sequential color scales for each visualization to avoid color overuse and make the darker color map higher data.
